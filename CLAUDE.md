# Claude Code

Your project rules are compiled into `.claude/rules/` and load automatically. Don't edit
them there — they're generated. See `.claude/rules/codebuddy-system.md`.

The spec index is maintained in the block below by `ccb sync`. It's here rather than
imported from `AGENTS.md`, because Claude Code inlines an import's whole contents and
this repo's `AGENTS.md` carries a rule index you already have in `.claude/rules/`.

## This file stays thin

Anything true of more than Claude belongs in `.codebuddy/rules/`, which compiles to all
six agent folders. Put something here only if it's specific to Claude Code.

## Attribution on PRs

Do not add a "Generated with Claude Code" footer to pull request descriptions. The
`Co-Authored-By` trailer on commits already records authorship; the footer repeats it
somewhere nobody needs it.
